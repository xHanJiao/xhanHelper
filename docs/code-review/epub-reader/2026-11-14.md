## 未覆盖 / 残余风险

- `scanBody` 与 `topLevelRanges` 都不处理命名空间前缀标签（`<xhtml:h1>`），这类书层级会退回平铺（不影响阅读与跳转）。
- `topLevelRanges` 仍不跳 `<script>` / `<style>`（`scanBody` 已跳）。正文带脚本的 EPUB 极少；真遇到时切节可能偏。
- `isPartTitle` / `endsPartGroup` 是标题文字启发式，误判只让目录多/少缩进一级。
- 未做 20MB 单章的真实耗时实测（322KB 真书全量解析 0.13s）。

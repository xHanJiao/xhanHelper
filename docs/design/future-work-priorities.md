# 未来工作评估与优先级

> 日期：2026-08-02
> 背景：macOS 客户端 + agent_browser 工具链一期完成后的远期规划讨论
> 范围：输入框功能 / 浏览器拟人 / 自动化工作 / 后台优化（缓存/长程/Plan&Execute/subAgent）

## 一、输入框美化与功能接入

| 子项 | 难度 | 关键路径 |
|------|------|---------|
| 会话智能体切换 | 低 | 后端已支持 agent_id 更新（PATCH conversations）；客户端输入框下拉 + 确认 |
| L3 确认开关 | 低 | 本地开关控制 riskLevel 拦截（L3 机制已就绪：pendingToolConfirmation） |
| macOS 语音输入 | 中 | SFSpeechRecognizer 权限 + 输入集成 |
| 模型切换 | 中-高 | 后端会话级 model 字段 + LLM 客户端选择逻辑 + 前端 UI |

收益：中（体验类）。智能体切换与 L3 开关可零成本先做。

## 二、浏览器进一步拟人（登录账号防封）

- 现状基础：随机延迟、贝塞尔轨迹、点击偏移、指纹伪装（plugins/WebGL/languages）、UA 对齐
- 进一步方向：行为模式层——滚动节奏、页面停留时间、操作间隔分布、浏览习惯模拟
- 难度：高（拟人是持续猫鼠游戏，平台风控变化不可预测）
- 收益：高但难验证（封号风险无法直接测试）
- 边际递减：个人低频使用下现有程度已够用，建议适度投入

## 三、自动化工作（任务流程确定后的后台执行）

- 目标：探索一次、固化脚本、后台定时执行（替代每次 LLM 驱动浏览器）
- 难度：中-高
- 关键设计：任务描述 → agent 生成步骤序列（DSL）→ 后台调度器执行 → 结果入库/通知
- 基座：BrowserToolProvider 工具链现成（open/snapshot/click/get_text...）
- 收益：高（真正省时间）

## 四、后台部分

### 4.1 缓存优化（命中率 50% → 80%+）

- 难度：中；收益：高（成本直接下降）
- 现状：agent 缓存命中率 ~50%，opencode 类工具 80%+，差距明显
- 待调研：现有缓存实现（deepseek 自动 context caching？自定义语义缓存？）
- 常见根因：prompt 动态前缀（时间戳/检索结果/会话状态变化）破坏缓存复用
- 优化方向：稳定 prompt 前缀结构（动态内容后置）、减少无谓变化、对齐 deepseek context cache 机制

### 4.2 长程任务（50 轮上限）

- 难度：中；收益：中-高
- 50 轮硬约束影响复杂任务完成率；到上限时上下文已巨大
- 需要：滚动窗口 + 历史摘要压缩；与 4.1 共享 prompt 结构优化

### 4.3 Plan & Execute

- 难度：中；收益：中-高
- 基础已存在：plan 事件流 + PlanModal 展示 + 一行字确认机制（L3 已验证）
- 需：编排层"计划模式"（先规划 → 用户批准 → 执行）+ 计划粒度控制
- 是 3（自动化）与 4.4（subAgent）的地基

### 4.4 subAgent（复用会话体系）

- 难度：高；收益：高
- 复用 Conversation：隐藏会话（可见性字段）+ 独立 ReAct 循环 + 子任务结果回传
- 复杂度：编排（子任务解析/错误处理/上下文传递）+ 会话体系扩展
- 依赖 Plan & Execute 成熟

## 五、优先级排序（难度 × 收益 × 依赖）

| 优先级 | 项目 | 理由 |
|--------|------|------|
| P0 | 4.1 缓存优化 | 钱袋子；难度中；先调研后优化，见效快 |
| P0 | 4.2 长程任务 | 50 轮硬约束；与 4.1 共享 prompt 结构优化 |
| P1 | 4.3 Plan & Execute | 机制基础已存在；是 3 和 4.4 的地基 |
| P1 | 3 自动化工作 | 探索→固化→后台执行收益最直接；工具链已就绪 |
| P2 | 1 输入框（智能体切换 + L3 开关先做） | 低成本体验项；模型切换/语音随需 |
| P2 | 4.4 subAgent | 能力质变但难度最高，等 4.3 成熟后做 |
| P3 | 2 浏览器拟人深化 | 边际递减 + 难验证；现有程度够用 |

## 六、推荐执行顺序

1. **4.1 缓存优化**：先调研现有缓存实现与命中率瓶颈（1 天），定优化方案
2. **4.2 长程任务**：滚动窗口 + 摘要压缩，与 4.1 的 prompt 结构优化一起做
3. **4.3 Plan & Execute**：编排层计划模式 + 用户批准
4. **3 自动化工作**：浏览器脚本引擎 + 后台调度
5. **1 输入框零成本项**（智能体切换 / L3 开关）穿插
6. **4.4 subAgent** / **2 拟人深化**后置

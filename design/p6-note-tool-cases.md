# P6 — record_note 交互设计

> 核心: 自由文本 + 可选标签 + 时间戳。录入零门槛，分析时 Pro 通读。

---

## 工具定义

```
record_note(topic, content, tags?)
  保存一条笔记

query_notes(topic?, keyword?, start_date?, end_date?)
  查询相关笔记，返回原文列表
  如果 "再帮我分析..." → Pro 通读 query_notes 结果 → 深度分析
```

---

## Case 1: 房地产追踪（纯政策 + 市场新闻）

```
用户: "今天自然资源部说，各地要合理控制新增住宅用地供应，去库存周期超36个月的城市暂停供地。"
  → record_note(topic="房地产", content="自然资源部：去库存周期超36个月的城市暂停新增住宅用地供应", tags=["政策","土地供应"])
  → agent: "已记录。这是典型的供给端收缩信号，如果叠加需求端刺激，房价可能企稳。有后续信号可以继续记录。"

用户: "上海链家出了数据，5月二手房成交1.7万套，环比涨了12%。"
  → record_note(topic="房地产", content="上海5月二手房成交1.7万套，环比+12%", tags=["上海","交易数据","二手房"])
  → agent: "已记录。成交量回暖，但还是要看价格——量在价先。"

用户: "我看了一个文章，说现在很多人宁租不买，因为租金收益率太低了。"
  → record_note(topic="房地产", content="观点：当前租金收益率过低，购房性价比不高。房价不跌到合理租售比，需求难真正释放。", tags=["观点","租售比"])
  → agent: "已记录。这个角度补充了前面的政策视角——供给收紧了，但需求端如果信心不恢复，量价还是会背离。"

用户: "最近有什么关于房地产的新信息吗？"
  → query_notes(topic="房地产")
  → agent: "最近3条记录：
    1. (前天) 自然资源部——暂停供地
    2. (昨天) 上海链家——二手房成交+12%
    3. (今天) 你的观点——租售比偏低阻碍需求
    想怎么分析？"

用户: "帮我分析一下这些信息，判断房价未来半年走势。"
  → Pro 深度分析
  → agent: "三条信息放在一起看：
    供给端：政府主动收紧供地（收缩）
    需求端：上海成交量回暖（回暖）
    基本面：租售比低（需求动力不足）

    矛盾在于：成交量在涨，但租售比说价格还没到位。
    我的判断：短期成交量继续回暖（政策托底），但价格难大涨（除非降息）。半年内大概率'量增价稳'。
    ⚠️ 但数据点太少——建议继续记录：新增房贷利率、二手房挂牌价变化、土拍溢价率。"
```

## Case 2: 睡眠追踪（混合：自由文本 + 可选的数值）

```
用户: "昨晚睡得不好，睡了大概5小时，中间醒了两次。12点半才放下手机。"
  → record_note(topic="睡眠", content="睡眠约5小时，断续醒2次，12:30放下手机。质量差。", tags=["失眠","熬夜"])
  → agent: "已记录。这已经是这周第三次了。要不要一起看看这周的睡眠记录？"

用户: "昨晚睡得不错，7个半小时一觉到天亮，23点就睡了，没喝咖啡。"
  → record_note(topic="睡眠", content="约7.5小时一觉天亮，23点入睡，无咖啡因摄入。质量好。", tags=["好眠","早睡"])
  → agent: "已记录。看来早睡+无咖啡的组合效果不错。"

用户: "帮我总结一下这个月的睡眠，看看什么因素影响最大。"
  → query_notes(topic="睡眠", start_date="2026-05-01")
  → agent返回10条记录
  → Pro 分析：
    "5月共记录10条睡眠笔记。
    好眠的共性：23点前入睡（4/4次好眠都早睡）、无咖啡因。
    失眠的共性：12点后入睡（5/5次失眠都熬夜）、当天喝过咖啡（4/5次）。
    
    最可能的影响因素：入睡时间。早于23点→好眠的概率是100%，晚于12点→失眠的概率是100%。
    咖啡因与睡眠质量负相关，但可能和入睡时间存在共线性。
    
    建议：保持23点前入睡一周，验证结论。"
```

## Case 3: 跨主题关联分析

```
用户: "这三个月我记录了不少东西，有房地产的、有宏观经济的、还有政策面的。帮我整体看看有哪些值得注意的趋势。"
  → query_notes(start_date="2026-03-01") → 返回30+条记录跨多个 topic
  → Pro 分析：
    "三个月记录梳理后，有三个交叉趋势值得关注：

    1. 政策面(6条) vs 市场面(8条)：政策在'放'（降息、松绑），但市场在'等'（成交量低迷、观望情绪浓）。政策传导滞后是正常的，但这次滞后比历史周期长。

    2. 房地产(5条) vs 宏观经济(4条)：房价下行和收入预期悲观形成负反馈。你记录的一个观点——'不降房价就先降收入，最终还是要降房价'——这个逻辑是自洽的。

    3. 睡眠(10条)：你的睡眠质量波动和咖啡因、入睡时间高度相关。这个结论比较可靠，建议优先干预。

    这些分析基于你记录的数据，数据密度不足的地方（如利率变化、租金数据）标了⚠️，建议后续关注。"
```

## Case 4: 观点迭代（自己跟自己辩论）

```
用户: "我之前觉得房价会大跌，但今天想了想，感觉政府不会让这个事情发生，因为银行扛不住。"
  → record_note(topic="房地产", content="修正看法：之前的'房价大跌论'可能有问题。银行体系承受不住大规模抵押物贬值，政府大概率会托底。但托底不等于涨，可能是阴跌+横盘。", tags=["观点修正","银行风险","政策托底"])
  → agent: "已记录。这个修正很重要——从'会不会跌'变成了'跌到什么程度会被托住'。下次有银行不良贷款率的数据可以对照验证。"

用户: "帮我回顾一下我关于房价的观点变化。"
  → query_notes(topic="房地产", keyword="观点")
  → Pro："你的观点演变：
    4月: 认为房价会大跌30%+
    5月初: 开始注意到租售比问题
    5月中: 修正为'阴跌+横盘'——政府会托底但不等于涨
    这显示你的思考在往'结构性而非方向性'转变。"
```

## 与记账的关系

```
记账 (bookkeeping)    → 结构化数据     → 金额统计、分类汇总
笔记 (record_note)    → 自由文本       → 主题追踪、趋势分析、观点迭代
```

两者共存，不互相替代。记账强调精度（金额必须准），笔记强调灵活（什么都记）。

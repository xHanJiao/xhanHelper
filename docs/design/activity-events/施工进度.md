## 一、施工约定（2026-09-26 定，勿擅自改）

- **基线分支**：`main`（已取消 `local-main`）。功能分支从 `main` 切。
- **包名**：`internal/activity`（emit + 存储，内聚独立）；后续派生放 `internal/activity/derive`。
- **存储层**：GORM（`gorm.io/driver/sqlite`，已在 `go.mod`）；events.db 与主库**不共用连接**。
- **Review 预算**：每期 Go 净改动（含测试）≤ ~250 行（S≤120 / M 120–250）。超了就拆下一期。
- **采集开关**：`activity.enabled` **默认开**（config 里 `*bool`，nil = 开）；云端 `APP_ENV=prod` 必须在 `conf/config.prod.yaml` 显式 `false`。非 sqlite（MySQL/云端）一律不启用。
- **验收**：主链路相关期给"真机跑一次聊天"的观察点；纯后台期只要求 `go build ./... && go test ./...` 绿。每期做完**停下等用户 review**，不自动进下一期。
- **只 `git add` 本期路径**，禁止 `-A`。提交前须用户同意。
- **施工中改文档**：设计/契约有变，先改附表 A/B 或设计篇，再改代码；进度记在本文件。

### P2 · emit 入口 ✅（2026-09-26）

**做了什么**
- `internal/activity/emit.go`（新）：`Event`（调用方只填语义字段）+ `eventRow`（events 表行，可空列用指针→落 NULL）+ `Emitter`（唯一 emit 入口）。
  - 公共字段由 `build` 补：`event_id`（空→uuid）、`occurred_at`（零→now，ISO8601 毫秒带时区）、`received_at`（UTC）、`schema_version`、`actor` 默认 system、`trigger` 默认 manual；调用方非空值不覆盖。
  - 背压：内存有界队列（1024），满则**丢最旧** + `Dropped()` 计数，`Emit` 非阻塞。
  - 批量：1 秒或 100 条先到先刷；`insertEvents` 一批一事务，`OnConflict{DoNothing}` 同时兜 `event_id` 主键与 `(type,biz_key)` 部分唯一索引。
  - `Flush()` 供里程碑立即刷；`Close()` 停 emitter 并刷完。
  - **空 `biz_key` 落 NULL**——空串会撞部分唯一索引，把无业务键事件互相吞掉。
- `internal/activity/db.go`：`Store` 持 `em`；`Open` 起 emitter；`Store.Emit/Flush` 委托；`Close` 先停 emitter。

**验收**
- `go build ./... && go test ./...` 绿，`go vet ./internal/activity/...` 干净。
- 单测：公共字段补全、调用方值不被覆盖、`event_id` 幂等、`(type,biz_key)` 幂等、无业务键多条都留、attrs JSON、队列满丢最旧且非阻塞。

### P21 · 归属推断 ref（只做 resource）✅（2026-09-28）

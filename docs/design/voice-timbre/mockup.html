提醒

macOS 设置（示意）：原生 Picker + 圆形试听按钮，不作为像素依据

入口

PWA：底部「我的」→ 设置 → 语音。macOS：⌘, → 设置 → 语音。语音未启用（ready=false）时整组不渲染，也不给禁用态。

保存与生效

选中即写本地（macOS UserDefaults / PWA localStorage），无「保存」按钮。合成请求带 speaker，空值回落服务端默认；从下一句开始生效。

试听与失败

试听复用 /api/voice/tts，固定一句约 20 字；再点一次停止，切换音色时先停。进入设置页先停当前朗读，避免两路音频打架。音色未开通或网络失败就地提示，保持原选择，不静默改音色。

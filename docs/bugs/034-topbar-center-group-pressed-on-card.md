# 034 · macOS：顶栏中心槽组显形后压在中间栏卡片上（降级宽度账不知道卡片右缘在哪）

> 2026-10-12 定位并修复。表现：右栏开着浏览器/文档面板时，窗口拖到「够宽」（浏览器 ≥1036 / 文档 ≥896）
> 中心槽组（浏览器 7 键 / 文档 3 键）从 `⋯` 回栏 —— 可它右对齐，回栏后整簇被推到**中栏卡片上**，
> 横跨卡片右上角（7 键那组压进去约 200pt）。窗口再窄一点反倒是正常的（中心槽组留在 `⋯` 里）。
> **状态：已修**（`swift test` 268 全绿 + 双端 `swiftc -typecheck` 0 error；真机清单见 §4）。

## 1. 问题表现

- 右栏开（非 PiP）+ 浏览器面板：窗口 ≥ **1036** 时中心槽组回栏，整簇左缘落在 `内容宽 − 16 − 599`；
  而卡片右缘在 `内容宽 − (cardGap 6 + seam 6 + 右栏 380)` → **窗口越宽差得越多**，那一簇压在卡片右上半区。
- 文档详情面板：窗口 ≥ **896** 时同样（3 键那组）。
- 反直觉点：**窗口更窄（双栏底线 778 那档）反而是对的** —— 那时「整栏装得下」这条判据先失败，
  中心槽组被挤进 `⋯` 了，纯属巧合。

## 2. 根因

顶栏那簇按钮是**右对齐**的（左侧红绿灯让位 + 会话下拉之后是弹性 `Spacer`），而中栏卡片占掉窗口左边一大块。
但降级只拿「窗口内容宽」算账（`TopBarLayout.plan(available:)` 只管 `width(level) ≤ available − margin`），
**不知道按钮簇只能待在卡片右侧那段**。于是「窗口够宽就显形」这条判据必然踩坑：
卡片宽 = 内容宽 − 12 − 右栏宽，**窗口越宽卡片越宽**，显形的中心槽组越容易落到卡片上。

`ContentView.swift`（`macOSContentArea`）上那句注释其实已经写明这条不变量：
「右栏关着时中栏铺满整宽，于是顶栏**所有**按钮都落在卡片里」—— 反过来说，**右栏开着时按钮不该落在卡片里**，
降级没有实现这后半句。

## 3. 最终方案（2026-10-12，用户拍 A）

给选档加**第二道闸**：右栏开且非 PiP 时，**低于 `foldCenter` 的档**（中心槽组还想显形的那些档）
还须满足 `trailingWidth(level) ≤ 中栏卡片右侧可用宽 − margin`，否则跳过该档。

- `TopBarLayout`：新增 `trailingChildren(level:model:)` / `trailingWidth(level:model:)`（右簇 = DEV 徽标 / 中心槽 /
  槽间线 / 右槽，与 `TopBarView.topBarHStack` 那几行一一对应）；`plan(available:trailingLimit:model:)` 加闸。
  `foldCenter` 及更深的档**不再过闸** —— 再往下降也缩不了右簇，不该无谓地把标签也收窄。
- `TopBarView`：新增入参 `trailingLimit: CGFloat?`（`nil` = 不限制）；隐藏探针与真实栏共用同一份 plan。
- `ContentView.topBarTrailingLimit`：`cardGap + seamHalfGap*2 + seamWidth + rightSidebar.width − toolbarHorizontalPadding`；
  右栏关着（卡片铺满整宽）/ PiP（整窗就是右栏）时返回 `nil`。

**可见后果**：右栏开着时中心槽组留在 `⋯` 里（标签上限不受牵连，仍是 240）。要把中心槽组换回栏上，
得把右栏拖宽到 **≥611**（浏览器）/ **≥471**（文档）；关右栏 / 进 PiP 行为与之前完全一致（中心槽组照旧能显形，
落在卡片上属 `../design/mac-card-top-wrap/design.md` 认过的形态）。

**已知边角**：右栏停在最小 380 时，「卡片右侧那段」= 376，而折叠态右簇 = 377 → `⋯` 左缘可能贴到卡片右缘
**1pt**。接受（要对齐得把顶栏右内边距 16 改成 12，会动左区几何与宽度账，不划算）。

**备选（未采纳）**：B = 右栏开就一律不许中心槽显形（扔掉「右栏够宽能回栏」这格）；
C = 把中心槽组摆进卡片里（Xcode 统一工具栏式，属布局重构，要出预览图）。

## 4. 验证

- 单测（`Tests/TopBarLayoutCoreTests/TopBarLayoutTests.swift`，+5 条）：右栏开时任何窗宽都不显形 /
  闸只收中心槽、不牵连标签（档位停在 `foldCenter` 而非末档）/ 右栏够宽能回栏且真落在限制内 /
  显形 ⇒ 必落在限制内（跨 300–900 限制 × 700–1400 窗宽）/ `nil` 限制与旧行为一致。
  全量 `swift test` **268 全绿**；macOS + iOS `swiftc -typecheck` 0 error。

### 真机清单（待跑）

# 活动埋点 · 完整回归测试计划

> **一句话**：在本地 dev 沙盒（Xcode **Debug** app / `local.dev` / SQLite）手工跑一遍全链路，再按本文「四、验收」逐项核对 `events.db` 与派生层。
> 关联：`施工进度.md`（实现状态）、`附表 A · 事件字典.md`（事件契约）、`活动埋点系统 · 实施技术方案.md`（设计）。

## 一、环境与约定

| 项 | 值 |
|----|----|
| 运行形态 | Xcode Debug 构建（macOS），`APP_ENV=local.dev`，端口 **18924** |
| 数据根 | `~/Library/Application Support/xhanHelper-dev/` |
| 事件库 | `~/Library/Application Support/xhanHelper-dev/events.db` |
| 后端日志 | `~/Library/Logs/xhanHelper-dev/backend.log` |
| 采集开关 | base `config.yaml` 的 `activity.enabled: true`（local.dev 不覆盖） |

**三条硬约定，先记住**：

1. **派生层只在启动（⌘R）时重算**：`Recompute` 由 cron 每节拍触发，节拍 =「启动一次 + 每晚一次」。所以手工动作做完后**必须再 ⌘R 一次**才会把派生表刷新到最新；否则派生层是旧的。
2. **`⌘R` = 停旧实例（落 `client.app.quit`）+ 起新实例（触发重算）**。因此「测退出」和「触发重算」用同一次 ⌘R 即可。
3. **验收按时间窗过滤**（本次开始时间之后的事件），避免和历史数据混。

## 二、前置：干净起步（可选，推荐）

目的：从零事件库开始，计数最干净、无需按时间窗过滤。

1. **⌘Q 退出 Debug app**（后端进程会随之退出，必须先退，否则删的是被占用的活文件）。
2. 确认 18924 已无监听：`lsof -nP -iTCP:18924 -sTCP:LISTEN`。
3. 备份后删除（**只动 `-dev` 这一份，绝不碰 `xhanHelper/`（prod）**）：

   ```bash
   DEV="$HOME/Library/Application Support/xhanHelper-dev"
   BK="/tmp/xhan-events-backup-$(date +%Y%m%d-%H%M%S)"; mkdir -p "$BK"
   cp -a "$DEV"/events.db "$DEV"/events.db-wal "$DEV"/events.db-shm "$BK"/   # 存在才拷
   # 只读校验备份可读（非必须）：sqlite3 -readonly "$BK/events.db" "SELECT count(*) FROM events;"
   rm -f "$DEV/events.db" "$DEV/events.db-wal" "$DEV/events.db-shm"
   ```

4. **⌘R** 重跑 → 全新库；启动应落 `client.app.launched` + `system.boundary`，并跑一次（空）重算。

## 三、测试步骤

> 每步「预期落库」是判据。做完记个大概时间点，验收按这个窗口查。

### 阶段 1 · 主对话链路（服务端事件）

| # | 动作 | 预期落库（事件 type） |
|---|------|----------------------|
| 1.1 | 发一条**不触发工具**的普通消息（如"你好，随便聊聊"） | `chat.message.sent`、`chat.turn.started`、`chat.turn.ended`、`llm.call.started`、`llm.call.ended`、`llm.first_token` |
| 1.2 | 让 agent **记账**（如"记一笔 25 元咖啡 餐饮"） | `tool.call.started/ended`（`attrs.tool_name=bookkeeping.*`）+ 系统变更 `bill.created` |
| 1.3 | 让 agent **建文档 → 改文档 → 删文档**（"新建文档《测试》，正文写 hello；把标题改成《测试2》；再删掉"） | `doc.created`、`doc.updated`、`doc.deleted` |
| 1.4 | 让 agent **记一条记忆**（"记住：我偏好深色模式"） | `memory.entity.changed`（`op=create`） |

## 四、验收清单

> 以下均为**只读**查询，`sqlite3 -readonly <events.db> "..."`。设 `DB` 为事件库路径。
> 干净起步（第二节）时无需时间过滤；否则加 `WHERE occurred_at >= '<本次开始 UTC>'`。

### 4.1 事件齐全性（按类型）
```sql
SELECT type, count(*) c, min(occurred_at), max(occurred_at)
FROM events GROUP BY type ORDER BY type;
```
**通过**：第三节各阶段列出的事件类型均 ≥1。

### 4.2 字段正确性（stamping）
```sql
SELECT type, count(*) tot,
       sum(conversation_id IS NOT NULL AND conversation_id<>'') conv,
       sum(turn_id IS NOT NULL AND turn_id<>'')          turn,
       sum(parent_event_id IS NOT NULL AND parent_event_id<>'') par,
       sum(pair_id IS NOT NULL AND pair_id<>'')          pair
FROM events GROUP BY type ORDER BY type;
```
**通过**：
- `chat.turn.*`、`tool.call.*`、agent 的 `browser.nav.*`、`client.tool.exec.*` 带 `conversation_id + turn_id`；
- `client.tool.exec.*` 的 `parent_event_id` = 对应 `tool.bridge.dispatched` 的 `event_id`（下方查询）；
- `owner=user` 的 `browser.nav.*` 的 conv/turn/parent 为空。

```sql
-- client.tool.exec 父链：每行 bridge_id 都非空才算对
SELECT s.event_id, s.parent_event_id, b.event_id AS bridge_id
FROM events s
LEFT JOIN events b
  ON b.type='tool.bridge.dispatched' AND b.event_id = s.parent_event_id
WHERE s.type='client.tool.exec.started';
```

### 4.3 区间闭合
```sql
SELECT e.type, i.closed_by, count(*) c
FROM interval_closed i JOIN events e ON e.event_id=i.start_event_id
GROUP BY e.type, i.closed_by ORDER BY e.type;
```
**通过**：成对事件（tool.call / llm.call / chat.turn / client.tool.exec / task / browser.nav / client.input）基本为 `paired`。

### 4.4 派生层出数
```sql
SELECT 'interval_closed' t, count(*) n FROM interval_closed
UNION ALL SELECT 'sessions',        count(*) FROM sessions
UNION ALL SELECT 'event_session',   count(*) FROM event_session
UNION ALL SELECT 'day_stats',       count(*) FROM day_stats
UNION ALL SELECT 'day_health',      count(*) FROM day_health
UNION ALL SELECT 'resources',       count(*) FROM resources
UNION ALL SELECT 'event_resources', count(*) FROM event_resources
UNION ALL SELECT 'event_refs',      count(*) FROM event_refs
UNION ALL SELECT 'event_edges',     count(*) FROM event_edges;
```
**通过**：除 `event_edges`（无生产者，预期 0）外全部 > 0；`event_refs` > 0（阶段 1.4 memory / 1.5 reminder 各映射一条）。

### 4.5 在场 / 电源
```sql
SELECT type, count(*) FROM events WHERE type LIKE 'system.%' GROUP BY type;
-- sleep/wake 与 boundary 的相邻关系
SELECT occurred_at, type FROM events
WHERE type IN ('system.sleep','system.wake','system.screens.sleep','system.screens.wake','system.boundary')
ORDER BY occurred_at;
```
**通过**：`system.screens.sleep/wake` 各 ≥1、`system.sleep/wake` 各 ≥1，且各自紧邻一条 `system.boundary`（同一批 / 时间相邻）。

### 4.6 提醒与读取自记
```sql
SELECT type, occurred_at, substr(attrs,1,80) FROM events WHERE type LIKE 'reminder.%' ORDER BY occurred_at;
SELECT type, count(*) FROM events WHERE type LIKE 'read.%' GROUP BY type;
```
**通过**：`reminder.created` 与 `reminder.acknowledged` 都在；`read.query` ≥1。

### 4.7 异常检查
```bash
# 后端日志无埋点/节拍报错、无 upload 4xx
grep -E "\[activity\]|\[cron\] activity" ~/Library/Logs/xhanHelper-dev/backend.log | grep -iE "error|fail|panic"
# 事件无重复（PK 已保证，仅兜底）
sqlite3 -readonly "$DB" "SELECT event_id,count(*) FROM events GROUP BY event_id HAVING count(*)>1;"
# 重算确已跑过（stamp + 时间）
sqlite3 -readonly "$DB" "SELECT key,value FROM meta WHERE key IN ('recompute_stamp','last_recompute_at');"
```
**通过**：第一条无输出；第二条空；第三条 `recompute_stamp=r1/t1/n1/f1` 且 `last_recompute_at` 为本次重启时刻。

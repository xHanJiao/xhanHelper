# 行尾两空格硬换行 / 字面方括号 划不上 —— flatten 少分隔符 + 方括号被当标记剥掉

## 问题表现

「特殊字符测试文档」（dev 沙箱 `8b6106ae-65bb-430e-b54a-545174b7d2ad`）里两处：

1. **行尾两空格（硬换行）**：选「`这一行末尾有两个空格`␠␠ 换行 `这是下一行`」这一段，划线画不出（抽屉里在、不在已失活、点它 toast 定位不到）。
2. **字面方括号**：整行选 `全角空格： [　]`，波浪线**只画到 `全角空格：` 就停**、不覆盖 `[　]`；只选 `[　]`（或 `[ ]`）时干脆什么都不发生（quote 变空 → 静默 return）。

复现源文：

```
- 全角空格： [　]

- 结尾带两个半角空格的行（Markdown 里表示换行）：
  这一行末尾有两个空格  
  这是下一行
```

## 根因 1：硬换行 `<br>` 在 flatten 里没有分隔符

marked（`breaks:false`）把「行尾两空格 + 换行」渲染成 `<br>`：`…两个空格<br>这是下一行`。

| 侧 | 该段投影 |
|---|---|
| 服务端 `project(src)` | `这一行末尾有两个空格 这是下一行`（两空格+换行折成**一个空格**） |
| 客户端 `flatten()` | `这一行末尾有两个空格这是下一行`（`<br>` 是元素、无文本节点；两侧文本节点同属一个块，不补分隔符） |

少一个空格 → 客户端 quote 与服务端投影对不上 → create 时 rung 2 失败、掉 rung 3 把 quote 改写成带空格版本 → 客户端永远搜不到。**任何文档里跨「行尾两空格硬换行」的划线都不行**。

## 根因 2：`[` / `]` 被当 Markdown 链接标记剥掉

`project()` / `fold()` 都把 `[` `]` 当行内标记丢掉（本意是抹掉链接 `[text](url)` 的方括号）。但 DOM 里链接渲染成 `<a>` 锚文本、**根本没有方括号**；正文里字面的方括号（如 `[　]`）却是实打实的字符、客户端 `fold` 一视同仁地也剥了。

下划线画的是「定位到的 quote 范围」：quote 被剥成 `全角空格：`（尾部 `[　]` 连方括号带空格一起没了），波浪线自然只盖到 `：`。若选区只有 `[　]`，`fold` 结果为空 → `createFromSelection` 里 `if (!info.quote) return` 静默什么都不做。

## 修复

1. **硬换行（客户端）**：`render()` 灌完 HTML 后，给每个 `<br>` 补一个 `'\n'` 文本节点（行内空白，渲染无影响）。`flatten` 就能拿到分隔符，折成空格与服务端对齐。
2. **方括号（两侧一起）**：从服务端 `mdInlineMarkers` 与客户端 `MD_MARKERS` 里**去掉 `[` 和 `]`**。字面方括号（及其内部空白，如 `[　]`）因此进入 quote 与下划线范围；链接目标 `(url)` 的噪声照旧（跨链接选区两边本来就对不上，不构成回归）。
3. **空选区提示**：`createFromSelection` 遇到折成空串的选区（纯空白 / 纯标记）不再是静默 return，改走 `post({type:'toast'})`，Swift 侧 `ToastCenter` 提示「选中的内容没有可锚定的文字，连旁边的字一起选」。

## 钉子

- `check-reader-html.sh` 新增：
  - **7d 方括号**：`方括号： [内容] 与 [ ]` 画 1 段 mark，且 `markText` **精确等于**整句（含尾部 `[ ]`）；再单独测 `[ ]` 能画上（旧实现 quote 为空 → 0 段）。
  - **7e 硬换行**：`行尾两空格硬换行␠␠\n这是下一行`，quote 带空格，断言画出 **2 段** mark（跨 `<br>` 两侧两个文本节点）。
- `document_anchor_test.go` 新增 `TestProjectKeepsLiteralBrackets`（`[内容]` / `[　]` 原样保留，`[　]` → `[ ]`）、`TestLocateLiteralBrackets`。
- **变异验证**：`MD_MARKERS` 加回 `[` `]` → 7d 的「覆盖到尾部方括号」与 7d 的 `[ ]` 用例变红；去掉 `<br>` 补 `\n` → 7e 变红。Go 侧把 `[` `]` 加回 `mdInlineMarkers` → `TestProjectKeepsLiteralBrackets` 变红。

## 存量脏数据

已被写坏（跨硬换行/含方括号）的划线记录不会自愈：删掉重划；或下次正文被改写触发 `RelocateAll` 时重锚。

## 留给以后的

- 跨 **Markdown 链接**（`[text](url)`）的选区两侧仍对不上：服务端投影留了 `(url)`、DOM 只有锚文本。链接少（3%），暂不处理。
- 纯空白选区（连方括号都不选）依旧无法锚定，现在至少会 toast 说明，不再静默。

JS 弹窗测试页

用于验证 xhanHelper 浏览器对 JS 对话框（alert / confirm / prompt）的处理。 历史问题：页面连续弹窗或加载中弹窗时，旧实现（runModal 嵌套 run loop）会崩溃（mach_msg2_trap + SIGABRT）。 修复后应全部以非阻塞 sheet 弹出，页面不卡死、不崩溃。

1. 单个 alert

最基础场景：弹一个提示框，点「好」关闭。

2. 单个 confirm

点「确定」返回 true，点「取消」返回 false，结果写入下方日志。

3. 连续 3 个 alert（崩溃复现器）

旧实现下第二次弹窗打进来时第一个 modal 还开着 → 嵌套 runModal → 崩溃。修复后应依次弹出 3 个 sheet。

4. alert + confirm 连发

先 alert 再 confirm，再 alert。验证不同对话框交替时的稳定性。

5. prompt

触发 textInput 面板。当前实现以「网页提示」展示，点好返回空字符串。

6. 模拟「加载即弹」

页面刚加载完立刻弹 alert（模拟真实站点 onload 弹窗），配合 handleOpen 的加载等待逻辑。

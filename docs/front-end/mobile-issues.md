# 移动端问题清单

记录移动端发现的问题和优化建议。

## 问题清单

### P1 - 高优先级

#### 1. 多个 resize 监听器
**文件**: `front-end/src/composables/useMobile.js`

**问题描述**:
- 每个组件调用 `useMobile()` 时都会添加一个独立的 `resize` 事件监听器
- 多个组件共存时会有多个监听器同时运行
- 可能导致性能问题

**建议修复方案**:
- 添加监听器计数逻辑
- 仅在第一个组件挂载时添加监听器
- 最后一个组件卸载时才移除监听器

---

#### 2. 抽屉遮罩无法点击关闭
**文件**: `front-end/src/App.vue`

**问题描述**:
- 移动端抽屉的半透明遮罩层点击时没有任何反应
- 用户期望点击遮罩可以关闭抽屉

**建议修复方案**:
- 给遮罩 `div` 添加 `@click="closeDrawer"` 事件

---

#### 3. 模态框固定宽度
**文件**: `front-end/src/views/AgentView.vue` 及其他视图

**问题描述**:
- 模态框固定 `width: 560px`
- 在小屏移动设备上可能超出屏幕宽度

**建议修复方案**:
- 改为 `width: 90%; max-width: 560px;`
- 确保在移动端也能正常显示

---

### P2 - 中优先级

#### 4. 缺少 viewport meta 标签
**文件**: 需要检查 `index.html`

**问题描述**:
- 没有设置 viewport meta 标签
- 移动端可能会有缩放、布局问题

**建议修复方案**:
- 在 `index.html` 中添加:
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no">
```

---

#### 5. 代码重复
**文件**: 各个视图文件

**问题描述**:
- 每个视图都有相同的汉堡菜单按钮代码
- 违反 DRY 原则

**建议修复方案**:
- 可以考虑提取成通用的 Header 组件（可选）
- 或者保持现状，视维护成本决定

---

### P3 - 低优先级

#### 6. 移动端 padding 可能过大
**文件**: 各个视图文件

**问题描述**:
- 部分视图使用 `var(--space-lg)` 在移动端可能太宽
- 占用宝贵的屏幕空间

**建议修复方案**:
- 可以考虑针对移动端调整 padding
- 或者使用更小的间距变量

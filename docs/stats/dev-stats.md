## 读数须知

- **merge 不产生 numstat**：`git log --numstat`（本脚本口径）不为 merge 出 diff，所以「最大单 commit」看不到经合并进来的工作量；提交总数也会被 merge 虚高。
- **vendored / 生成物会虚增行数**：第三方源码整包导入 +94,417 行，提交进仓库的数据/锁文件 +37,295 行，两者都已在「手写」口径剔除。
- **line ≠ 有效代码量**：含注释、文档字符串、生成物；vendor 与 docs 尤其不适合当产出指标。
- **按区域含历史目录**：区域按「提交当时的路径」归类，后来删除/改名的顶层目录（如早期的 `design/`、`server-py/`）单独成行，不等于当前布局。
- **类型分布依赖 conventional commits**：只认 feat/fix/docs/refactor/chore/perf/test/build/ci/style/revert/config，其余全归 `other`。

## 发现

### P1 - High

1. **重放对比页渲染即崩：`configB.theme` 已从默认值删除，模板还在读它**
   - 位置：`front-end/src/views/ReplayCompareView.vue:277`（「主题检索」列头）、`:281`（`v-model.number="configB.theme.threshold"`）、`:285`（`configB.theme.limit`）；对照 `:33-40` 的 `defaultConfigB` 已在本次提交里删掉 `theme: { threshold, limit }`。
   - 现象：`configB = ref({ ...defaultConfigB })`，`configB.theme` 是 `undefined`。Vue 模板把 `v-model` 编译成 `withDirectives(..., [[vModelText, configB.theme.threshold, ...]])`，渲染时求值 `undefined.threshold` → `TypeError`，配置 B 面板所在的整页渲染失败（该面板无 `v-if`，锚点消息加载完进入 `v-else` 就命中）。
   - 证据：`vite build` 产物里能直接看到 `[[t,K.value.theme.threshold,...]]`（`dist/assets/ReplayCompareView-*.js`）；`vite build` 本身不做模板成员检查，所以构建是绿的。
   - 影响面：仅 admin 的「对话重放对比」页，但页面完全不可用；这是本次删配置时漏改模板，不是既有问题（上一版 `defaultConfigB` 有 `theme` 键）。
   - 建议：删掉「主题检索」列头 + 两个 `v-model`（连同 `:277/:281/:285` 与 grid 的 4 列改 3 列）；后端 `replayPreviewReq` 已无 `theme` 字段，保留默认值也没意义。

### P2 - Medium

2. **iOS/macOS 客户端仍调 `/api/themes`，路由已删 → 「主题」浏览页 404**
   - 位置：`client/xHelper/xHelper/Shared/Services/APIClient.swift:1122`（`get("/api/themes?...")`）、`ViewModels/ThemeViewModel.swift:24`、`Views/BrowsePanelView.swift:15`（`.themes = "主题"` 枚举）、`:1088`（`ThemePage(viewModel:)`）、`Views/PageHolders.swift:74`、`Views/RightSidebarView.swift:14`。
   - 影响：客户端「主题」tab 会稳定报错（`ThemeViewModel.load` 捕获后显示 `errorMessage`），右侧栏/内容区仍保留入口。设计里这批 UI 要到阶段 7 才换 EventView，但阶段 5 先把接口删了，中间这几轮客户端是坏的。
   - 建议（择一，明确记进阶段表即可）：
     - 阶段 5 保留一个只读 `GET /api/themes`（`ListNotDraft` 查询仍在），等阶段 7 连 UI 一起删；或

3. **模型侧仍在宣传「主题」：系统 prompt 与 `unified_search` 描述没跟着改**

     - `server/internal/agent/promptbuilder/static.go:20`「主动检索相关记忆、笔记、**主题状态**」、`:39`「画像/记忆/笔记/摘要/**主题**/历史后综合回答」；

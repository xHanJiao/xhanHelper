## 问题清单

### P1（已修）

1. **JS 求值可能永久挂起**（`CefBridge.mm` `evaluateJavaScript:completion:`）
   - 现象：超时块只持 `__weak self`；视图先 dealloc、`OnBeforeClose` 还没到时直接 `return`，continuation 永不 resume → agent 的一次 `await evaluateJS` 卡死整轮对话。
   - 修法：超时块改为**强持有回包字典**（不持 self），仍能把还等着的 block 失败掉；`dealloc` 里再把残留求值一次性失败（`dispatch_async`，不在析构栈里 resume Swift）。

### P2

2. **弹窗视图搬家时自己可能还没有窗口**（`CefBridge.mm` `cefBrowserCreated:`）—**已修**
   - 现象：弹窗 tab 是同步建的，`OnAfterCreated` 时 SwiftUI 还没把视图挂进侧栏；渲染视图搬进一个没有窗口的父视图 = B7 那个「页面永不 commit」。
   - 修法：搬家前先 `parkInHiddenWindowIfNeeded`（把 `createBrowserIfNeeded` 里那段停车逻辑抽成方法复用）。

3. **媒体提示条不随导航复位**（`BrowserTabView.swift` / `BrowserPage.swift`）—**已修**
   - 现象：在 A 站看到「需要 H.264」后，同 tab 导航到 B 站提示条还在，按钮会把 B 站以兼容引擎打开。
   - 修法：`mediaHintHost` 记弹条时的 host，host 变化即收起；`CefPage` 在 `urlDidChange` 命中新 host 时清 `mediaIssueReason`。

4. **fill/select/check 的传输层错误被吞**（`BrowserToolProvider.swift`）—**已修**
   - 现象：改走 `jsJSON` 后丢了 `jsError`，「超时 / 页面还没准备好 / 渲染进程不可用」统一变成「元素交互失败：JS 异常」，与 `docs/bugs/065` 要修的谎报同类。
   - 修法：新增 `jsJSONResult`（`(value, jsError)`），`interpretRefResult` 增加 `jsError` 参数；4 个交互调用点全部透出。

5. **弹窗 tab 丢失 agent 归属**（`BrowserToolProvider.swift`）—**已修**
   - 现象：agent 触发 `window.open` 出来的页 `owner=nil` / `isAgentTab=false`：不计入 agent 配额、`close_all` 收不掉，agent 自己写还得要用户授权。
   - 修法：`adoptCefPopupPage(_:urlString:opener:)` 从 opener 继承 `isAgentTab` / `owner`，agent 弹窗不切走用户视图（与 WK 弹窗同一口径）。

6. **媒体探针第 2 层误报**（`CefDisguise.h` `MediaProbeJavaScript`）—**已修**
   - 现象：`loadstart` 只判「本机不支持 H.264」就报，VP9/WebM 页面明明能播也会被劝去兼容引擎，与「只报确定坏」相反。
   - 修法：`loadstart` 先看源是否像 H.264（`.mp4/.m4v/.mov`，含 `<source>`），判不出来的（`blob:` / 无 src / MSE）不报——真坏会落到第 3 层 `error.code === 4`。

7. **CEF 标签的下载拿不到 Cookie**（`BrowserToolProvider.swift` `handleDownload`）—**未修，记待办**
   - 现象：`download` 的 Cookie/Referer 取自 `session.webView`，CEF 标签为 nil → 需登录的媒体下载从「成功」退化为 403（只有 diag 日志，用户侧表现为「需要登录」）。
   - 方向：CEF 侧从 `CefCookieManager`（profile 里的 cookie）取，或明确回结构化降级原因。下一批处理。

### P3

8. **`check/uncheck` 状态本来就对时仍派发 change**—**已修**：只在真的点了（`before !== checked`）才派发。
9. **selector 版 `select` 找不到元素时丢掉 selector 文本**—**已修**：错误里带上选择器。
10. **`XHPROBE:` / `XHMEDIA:` 前缀对页面可见**（页面可自己 `console.error` 驱动原生回调）—**未修**：影响面只是「伪造一条换引擎提示」，下一批可加注入时生成的一次性 nonce。
11. **`OnBeforePopup` 依赖 `RunOnMain` 同步**（若回调不在主线程，弹窗会被取消并留 `[cef] popup dropped … no host`）—**不改**：CEF 的 UI 线程就是主线程，日志已能定位。
12. **`fillGuardJS` 现在拒绝 `<select>` 与 `input[type=hidden]`**—**是行为收窄**：`fill` 填 select 本来就该走 `select` 工具，错误文案已显式指路。

## 已确认没问题（不必重复看）

- 弹窗 client 独立性：每个 popup 单独 `new XHCefClient(popupView)`，不会把地址/标题/`OnBeforeClose` 串到 opener 上。
- `cefBrowserDidClose` 只放 `_browser`、client 留到 dealloc，没有「成员函数执行中 delete this」。
- 弹窗视图在 `popupPageRequested` 同步回调后由 Swift 强持有；`_closeRequested`（创建窗口期秒关）复用既有兜底；12s 兜底只在没拿到 browser 时触发。
- 页面自关窗走 `dispatch_async` 通知宿主，不在 `OnBeforeClose` 栈里关 tab；`!_closeRequested` 能区分主动关/自关。
- JS 求值三条路径（回包 / 10s 超时 / 关页）用字典取走，不会二次 resume；信封解析失败都有明确 error。
- 渲染进程 `EvalWrapper` 用 `(0,eval)` + 字面量转义；`OnProcessMessageReceived` 的参数不足属于协议异常分支，不是吞业务错误。
- `download` 提到 tabId 闸门之前确实解开死循环，且仍走危险扩展名 / 域名匹配 / magic number 三道闸。
- `read(filter)` 未命中改 serverError、`get_text` 透出 jsErr、`click_text` 换 `innerText`。
- `switchActiveTab` 对 CEF（`webView == nil`）跳过保活/暂停，不会误伤。
- 设计文档 §9.2.12–§9.2.14 与实现口径一致（含 D19 / D20）。
